# Front-end VELORA

React + Vite. A interface consome a API REST em `VITE_API_URL` e usa o cliente Supabase apenas para manter/renovar a sessão do Supabase Auth no navegador.

Variáveis:

```env
VITE_SUPABASE_URL=https://SEU-PROJETO.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
VITE_API_URL=http://localhost:3001/api
```
