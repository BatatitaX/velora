# Front-end

- `models/`: entidades de domínio (`Product`, `Customer`, `Sale`, `SaleItem`).
- `controllers/`: regras da interface e coordenação dos casos de uso.
- `views/`: componentes React.
- `core/EventBus.js`: comunicação orientada a eventos.
- `services/SupabaseService.js`: cliente da API REST e manutenção da sessão Supabase Auth.
